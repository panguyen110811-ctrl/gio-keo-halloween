# gio-keo-halloween
🎃 CHÀO MỪNG BẠN ĐẾN VỚI GIỎ KẸO HALLOWEEN!  Nhiệm vụ: Chọn một chiếc kẹo, viết lời nhắn hoặc lời chúc bí mật (dưới 50 từ) để góp kẹo vào giỏ chung.  Lưu ý nhỏ: Giữ lời nhắn văn minh, tích cực và đúng tinh thần "cho kẹo hay bị ghẹo" nhé!  Cùng bấm chọn kẹo bên dưới để xem viên kẹo của bạn bay vào giỏ bí ngô ngay nào 👇
